## 1. 安装与快速启动

Vector Toolbox 深度适配 **Adobe Illustrator 2021、2022、2023、2024、2025、2026+ (v25.0 ~ v30.0+)**，支持 Windows 与 macOS 平台。

### 方式 A：Windows 一键安装 (推荐)
1. 从 GitHub Releases 下载资产 `Vector-Toolbox-Setup.exe`；
2. 双击安装程序并允许管理员权限，无需手动解压；
3. 安装器会把程序复制到 `%APPDATA%\VectorToolbox`，再检测本机 Illustrator 并创建启动入口；
4. 安装完成后重启 Illustrator，在 **【文件】** -> **【脚本】** -> **【Vector-Toolbox】** 中启动。

当前 EXE 尚未进行代码签名。如果 Microsoft Defender SmartScreen 弹出，请先确认文件来自本仓库的官方 Release，再点击 **更多信息** -> **仍要运行**。

### 方式 B：macOS 一键安装 (推荐)
1. 从 GitHub Releases 下载资产 `Vector-Toolbox.zip` 并解压，然后在终端进入解压目录：
   ```bash
   cd /path/to/vector-toolbox
   bash install-macos.sh
   ```
2. 程序会安装到 `~/Library/Application Support/VectorToolbox`。安装后可删除解压目录；重启 Illustrator 后从脚本菜单启动。

### 方式 C：Illustrator 内置免安装直接运行
1. 打开 Illustrator，按下快捷键 `Ctrl + F12` (Windows) 或 `Cmd + F12` (macOS)；
2. 选择根目录下的 `Vector-Toolbox.jsx` 打开；
3. 或运行 `Install-VectorToolbox.jsx`，将程序复制到稳定目录并交互式写入脚本菜单。

## 3. 内置工具深度使用说明

### 3.1 标注工具套件

#### 1. 宽高标注 (`scripts/annotation/dimension.jsx`)
- **运行模式**：常驻浮动面板 (`palette`)
- **功能**：为选中的矢量图元生成宽高标注线；未选对象时标注当前画板。
- **核心参数**：
  - **标注方位**：上/下（宽）、左/右（高），可任意组合；
  - **单位换算**：支持 `mm`、`cm`、`pt`、`px`、`inch`；
  - **精度控制**：0 ~ 3 位小数；
  - **图层隔离**：写入 `__标注__` 图层，重复打开面板只会激活已有窗口；面板内「清除标注」只删该图层，不影响页码。

#### 2. 生成页码 (`scripts/annotation/page-number.jsx`)
- **运行模式**：模态弹窗 (`dialog`)
- **功能**：为全部画板生成页码，并可在对话框内清除旧页码。
- **核心参数**：
  - **格式**：`01 / 24`、`01`、`P.01`、`01 of 24`，或自定义 `{current}` / `{total}`；
  - **字体与字号**：从本机字体列表选择；
  - **位置**：右下 / 左下 / 右上 / 左上，横向与纵向边距分开设置；
  - **编号**：起始页码与最少位数，预览区即时显示。

#### 3. 清除标注 (`scripts/annotation/clear-annotations.jsx`)
- **运行模式**：一键执行 (`action`)
- **功能**：快速清理当前文档中所有的标注图层与页码图层。

---

### 3.2 色彩工具套件

#### 4. 色板色卡提取 (`scripts/color/palette-extractor.jsx`)
- **运行模式**：模态弹窗 (`dialog`)
- **功能**：从选区提取纯色填充/描边，在选区下方生成换行色卡；渐变与图案会跳过并提示。
- **适用场景**：VI 规范制作、品牌色板提案、UI 设计规范整理。

#### 5. 同色批量替换 (`scripts/color/replace-color.jsx`)
- **运行模式**：模态弹窗 (`dialog`)
- **功能**：查找指定的 HEX 颜色值（例如 `#000000`），并全局批量替换为新颜色（例如 `#FF5500`）。
- **参数控制**：可分别勾选是否替换「填充色」和「描边色」，支持处理选区或全文档。

---

### 3.3 文本排版套件

#### 6. 转曲并备份 (`scripts/text/outline-and-backup.jsx`)
- **运行模式**：模态弹窗 (`dialog`)
- **功能**：可选当前选区或全部可见文本转曲；默认备份到 `__原文字备份__`，已在备份层的文字不会再复制。

#### 7. 批量文本替换 (`scripts/text/batch-text-replace.jsx`)
- **运行模式**：模态弹窗 (`dialog`)
- **功能**：跨画板对所有文本框（或选中文本框）进行全文查找与批量替换，支持区分大小写与批量文案修正。

---

### 3.4 参考线工具套件

#### 8. 栅格参考线 (`scripts/guide/grid-guides.jsx`)
- **运行模式**：常驻浮动面板 (`palette`)
- **功能**：按 GuideGuide 思路在画板或选区上叠加参考线。
- **核心参数**：
  - **范围**：当前画板 / 全部画板 / 选区；
  - **边距**：四边相同，或上/右/下/左分开；
  - **列 / 行**：各自的数量与间距，可选在间距中加中线；
  - **快捷**：四边、水平+垂直中线、清除（生成会叠加，不覆盖）。

---

### 3.5 对象与路径套件

#### 9. 闭合开放路径 (`scripts/object/close-paths.jsx`)
- **运行模式**：一键执行 (`action`)
- **功能**：针对 CAD、外部导入 SVG 或手绘描摹图元中的未闭合断开线段，一键批量检测并封闭路径，便于后续着色与布尔运算。

#### 10. 批量重命名 (`scripts/object/batch-rename.jsx`)
- **运行模式**：模态弹窗 (`dialog`)
- **功能**：批量规范选中图元名称，支持前缀、后缀、查找替换以及递增序号（`#`、`01`、`001`）。

#### 11. 统一尺寸 (`scripts/object/normalize-size.jsx`)
- **运行模式**：模态弹窗 (`dialog`)
- **功能**：将选中对象统一为指定宽度、高度或最长边；目标数值默认取第一个有效对象的宽度，可锁定宽高比。

#### 12. 清理对象 (`scripts/object/cleanup-objects.jsx`)
- **运行模式**：一键执行 (`action`)
- **功能**：一键清理文档隐藏对象、孤立锚点、未着色路径与空文本框，大幅减小文件体积。

#### 13. 随机排列 (`scripts/object/random-arrange.jsx`)
- **运行模式**：模态弹窗 (`dialog`)
- **功能**：对选中对象批量施加随机角度旋转、位置散落抖动与等比缩放，快速制作背景肌理与散落图案。

---

### 3.6 画板工具套件

#### 14. 排列画板 (`scripts/artboard/arrange-artboards.jsx`)
- **运行模式**：模态弹窗 (`dialog`)
- **功能**：按指定列数（如 4 列、6 列）与间距（mm）将错乱的画板整齐重排为矩形网格，并可联动移动画布内容。

#### 15. 画板重命名 (`scripts/artboard/rename-artboards.jsx`)
- **运行模式**：模态弹窗 (`dialog`)
- **功能**：批量对所有画板按编号规则统一重命名（如 `Page_01`、`Screen_#`）。

#### 16. 选区生成画板 (`scripts/artboard/create-from-selection.jsx`)
- **运行模式**：一键执行 (`action`)
- **功能**：根据当前选中的图元外框尺寸，自动在其位置创建紧密贴合（或带内边距）的新画板。

---

### 3.7 智能导出与切图套件

#### 导出 PDF (`scripts/export/export-pdf.jsx`)
- **运行模式**：模态弹窗 (`dialog`)
- **功能**：将画板导出为 PDF，默认合并为一个多页文件；也可每个画板单独一份。
- **核心参数**：
  - **范围**：全部画板 / 当前画板 / 指定范围（如 `1, 3, 5-8`）；
  - **输出**：默认「合并为一个多页 PDF」，可改为「每个画板单独一个 PDF」；
  - **PDF 预设**：直接读取当前 Illustrator 的全部 PDF 预设，并统一应用于所有导出路径；
  - **大小估算**：按需抽样最多 3 个代表画板，分别显示可编辑版、转曲版及合计的近似区间；修改范围、输出模式、预设或版本勾选后需重新估算；
  - **可编辑版 / 转曲版**：可同时勾选；转曲走文档副本，不影响原稿；
  - **文件名**：可勾选「包含日期时间」，并选择三种格式（`20260818`、`2026-08-18`、`20260818_1430`）；预览区即时显示最终文件名。

大小估算需要执行临时 PDF 导出，因此不是即时计算。转曲版估算要求文档已保存且没有未保存改动；估算结果只用于判断量级，正式导出完成后状态栏会显示实际总大小。

#### 17. 智能导出 (Smart Export Pro) (`scripts/export/smart-export.jsx`)
- **运行模式**：模态弹窗 (`dialog`)
- **功能**：高级全功能切图与画板导出中心。
- **特性清单**：
  - **范围自由**：全部画板 / 当前激活画板 / 自定义范围（如 `1, 3, 5-8`）；
  - **多格式多选同时输出**：可同时勾选 PNG-24、JPG、SVG、PDF；
  - **多倍率**：可同时勾选 1x / 2x / 3x / 300 DPI（仅栅格格式）；
  - **命名模版**：`{doc}` `{name}` `{index}` `{index2}` `{scale}` `{format}` `{date}` `{w}` `{h}`，对话框内实时预览；
  - **子目录**：可选按格式分文件夹；PDF 导出后若原稿是已保存的 `.ai`，会重新打开原稿。

#### 18. 按图层批量导出 (`scripts/export/export-layers.jsx`)
- **运行模式**：模态弹窗 (`dialog`)
- **功能**：将文档所有可见顶级图层分别独立导出为透明 PNG 或 SVG 资源，UI 图标与组件切图必备。

#### 19. 快速导出 PNG (`scripts/export/quick-export-png.jsx`)
- **运行模式**：一键执行 (`action`)
- **功能**：一键以 300 DPI 极速导出当前正在查看的画板为高清透明 PNG。

## 4. 高级技巧与自定义扩展

### 快速新增你的专属工具
1. 在 `scripts/<分类>/` 目录下新建一个 `.jsx` 文件（如 `scripts/object/my-action.jsx`）；
2. 在 `config/tools.jsx` 中注册该工具：
   ```javascript
   {
       id: "my-action",
       name: "我的专属工具",
       category: "对象",
       script: "scripts/object/my-action.jsx",
       mode: "action", // 可选 "action" | "dialog" | "palette"
       keywords: ["自定义", "极速", "处理"],
       description: "执行自定义图元处理逻辑"
   }
   ```
3. 在 Vector Toolbox 主面板点击 **↻ 刷新**，新工具立即生效可用！

## 5. 常见问题排错 (FAQ)

### Q1: 运行安装脚本提示权限不足或未能找到目录？
- **Windows**：优先运行 `Vector-Toolbox-Setup.exe` 并允许管理员权限。ZIP 备选方式需右键点击 `install-windows.bat` 选择 **“以管理员身份运行”**；如果安装在非标准路径，可在 Illustrator 中使用 `Ctrl+F12` 运行 `Install-VectorToolbox.jsx` 交互式选择路径。
- **macOS**：在终端中使用 `sudo bash install-macos.sh` 运行。

### Q2: 点击工具后 Illustrator 没有反应？
- 检查当前是否有正在编辑的文本框或处于隔离模式，按下 `Esc` 退出隔离状态后再试；
- 查看 Vector Toolbox 底部状态栏的提示信息（例如“⚠ 请先选择对象”）。

### Q3: 为什么修改了工具代码后没有变化？
- 在 Vector Toolbox 面板底部点击 **【↻ 刷新】** 按钮即可重新载入脚本配置。
